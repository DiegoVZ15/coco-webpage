From GitHub to your first CBZ

Set up CoCo on your computer and send the file to your favorite reader.

  1. Download the project

    In the CoCo repository, choose Code → Download ZIP. Extract the ZIP and open the folder containing iniciar.bat.

    How to download the ZIP

  2. Run iniciar.bat

    Double-click the file. On the first run, it creates a .venv environment and installs the dependencies. CoCo then opens a terminal with prompts in Spanish.

  3. Choose a series and its chapters

    Enter the comic title at Nombre del cómic. Then enter the number next to the series and the positions shown in the chapter list. Check the titles for specials or annuals.

    1
    One chapter
    1-6
    A range
    1,3,5-8
    A mix of both

  4. Open your file

    When CoCo says 'CBZ completo guardado en', your file is ready in the descargas folder. Open the .cbz in your reader or copy it to your phone or tablet first.

Frequently asked questions

What is a CBZ file?

A CBZ is a ZIP archive containing the comic's images. Open it directly in a compatible reader to see the pages in order.

Can I resume an interrupted download?

Yes. Restart CoCo, find the same series, and choose the same chapters and output folder. CoCo reuses the verified images it saved in .progreso.

What if Windows can't find Python?

Install Python with pip and run python --version in a new PowerShell window to check that it works. Then open iniciar.bat again.

What if no series or chapters appear?

Check your internet connection and try searching for part of the title. If several series are affected, check the repository for updates about changes to the page catalog or reader.
