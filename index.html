De GitHub a tu primer CBZ

Instala CoCo en tu computadora y lleva el archivo a tu lector favorito.

  1. Descarga el proyecto

    En el repositorio de CoCo, abre Code → Download ZIP. Descomprime el archivo y abre la carpeta que contiene iniciar.bat.

    Ver cómo descargar el ZIP

  2. Ejecuta iniciar.bat

    Haz doble clic en el archivo. La primera vez crea el entorno .venv e instala las dependencias. Después aparece el buscador de CoCo.

  3. Elige la serie y sus capítulos

    Escribe el título, selecciona el número de la serie y luego las posiciones de los capítulos. Revisa los títulos si aparecen especiales o anuales.

    1
    Un capítulo
    1-6
    Un rango
    1,3,5-8
    Una combinación

  4. Abre tu archivo

    Cuando veas CBZ completo guardado en, abre la carpeta descargas. Importa el .cbz en tu lector o cópialo primero a tu teléfono o tableta.

Preguntas frecuentes

¿Qué es un archivo CBZ?

Es un archivo ZIP con las imágenes del cómic. Ábrelo directamente con un lector compatible para ver las páginas en orden.

¿Puedo continuar una descarga interrumpida?

Sí. Abre CoCo de nuevo, busca la misma serie y elige los mismos capítulos en la misma carpeta de destino. CoCo reutiliza las imágenes verificadas que guardó en .progreso.

¿Qué hago si Windows no encuentra Python?

Instala Python con pip y verifica que el comando python --version funcione en una ventana nueva de PowerShell. Después vuelve a abrir iniciar.bat.

¿Qué hago si no aparecen series o capítulos?

Comprueba tu conexión y busca con una parte del título. Si el problema afecta a varias series, consulta el repositorio por posibles cambios en el catálogo o en el lector de Marmota.
